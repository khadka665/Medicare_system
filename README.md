# MediCare Pro

MediCare Pro is a modern healthcare management platform designed to connect patients with doctors through a secure and responsive digital system.

## Features
- Doctor profiles
- Appointment booking
- Patient portal
- AI-powered healthcare support
- Responsive modern UI

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- MongoDB

## Future Scope
- Telemedicine
- AI symptom checker
- Online payments
- E-prescription system
